# Icons

Aset final sudah tersedia, digenerate dari
`public/images/naniash/naniash.png` (aset generik resmi aplikasi):

- `icon-192.png` — 192×192 (purpose: any)
- `icon-512.png` — 512×512 (purpose: any)
- `maskable-icon-512.png` — 512×512, konten dipusatkan dalam safe zone
  (~59% dari kanvas) supaya tidak terpotong oleh mask Android (circle,
  squircle, rounded-square, dll.)
- `apple-touch-icon.png` — 180×180, khusus iOS (iOS tidak baca ikon
  maskable dari manifest)
